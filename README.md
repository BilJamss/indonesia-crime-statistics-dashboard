# Indonesia Crime Statistics Dashboard

## Project Overview
An interactive dashboard developed using Python and Streamlit to analyze crime statistics in Indonesia based on data from the Badan Pusat Statistik (BPS).

## Objectives
- Analyze crime trends in Indonesia from 2019 to 2023.
- Compare crime statistics across Indonesian police regions (Polda).
- Analyze crime case resolution rates.
- Identify the most and least frequent crime categories.

## Tools & Technologies
- Python
- Pandas
- Streamlit
- Data Visualization

## Key Insights
- Crime cases decreased between 2019 and 2021, before increasing significantly in 2022 and 2023.
- DI Yogyakarta recorded the highest case resolution rate at 83.72%.
- Papua Barat recorded the lowest case resolution rate at 27.87%.
- Narcotics and psychotropic-related crimes were the most frequent category.

## Project Structure
- `Tubes.py` – Main dashboard application.
- CSV files – Crime statistics datasets.
- PNG files – Dashboard visualizations.
- `requirements.txt` – Python dependencies.

## How to Run

1. Clone this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the application:
   `streamlit run Tubes.py`

Link : https://indonesia-crime-statistics-dashboard-1504.streamlit.app/
